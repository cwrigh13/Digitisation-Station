# Equipment Specifications

Complete technical documentation for all equipment at the Digitisation Station.

## Video Digitisation Equipment

### Blackmagic ATEM Mini Pro ISO

**Purpose**: Video switch with USB recording capability

**Model**: ATEM Mini Pro ISO

**Key Features**:
- HDMI input capture from VHS/DVD player
- Direct recording to USB drive as MP4 files
- Real-time preview monitoring
- Audio level control
- Physical recording keypad with visual feedback

**Technical Specifications**:
- Video Input: 4x HDMI (using input 1 for LG player)
- Video Output: HDMI, USB-C
- Recording Format: H.264 MP4
- Recording Quality: 1080p HD
- Audio: Embedded HDMI audio, adjustable levels
- Storage: USB-C drive (bring your own or library-provided)

**Physical Controls** (Keypad):
- **REC button**: Start/stop recording
- **DISK light**: 
  - Green: USB drive connected and ready
  - Red: Recording in progress
  - Off: No USB drive detected
- **Channel ON/OFF buttons**: Audio control for each input
- **Channel select buttons**: Choose video source (Camera 1-4)
- **Program button**: Select output view
- **USB-C port** (back of keypad): USB drive connection point

**Important Notes**:
- USB port is on the BACK of the keypad unit
- Port marked with bright tape for visibility
- Must press REC before pressing PLAY on VHS player
- Audio must be ON throughout recording or video will have no sound
- Recording happens in real-time (60 min tape = 60 min recording)

**Common Issues**:
- DISK light not green: USB drive not properly connected or not compatible
- No sound in recording: Channel 1 audio was turned off during recording
- File not created: REC not pressed before PLAY, or recording not properly stopped

### LG DVD/VHS Combo Player

**Purpose**: Playback device for VHS tapes and DVDs

**Model**: 3850R-Z243R

**Key Features**:
- Dual media support (VHS and DVD)
- HDMI output to ATEM Mini
- Standard playback controls

**Technical Specifications**:
- VHS Playback: Standard VHS, NTSC/PAL
- DVD Playback: DVD, DVD-R, DVD-RW
- Output: HDMI (connected to ATEM Mini Pro ISO)
- Controls: Play, Stop, Pause, Fast Forward, Rewind, Eject

**Physical Controls**:
- **VHS slot**: Top loading for VHS cassettes
- **DVD tray**: Front loading for DVD discs
- **Playback controls**: Standard transport buttons on front panel
- **Eject**: Separate buttons for VHS and DVD

**Important Notes**:
- Always rewind VHS to start before recording
- Check tape is inserted correctly (label side up)
- Do NOT fast-forward during recording
- Ensure HDMI cable is securely connected

**Supported Formats**:
- ✅ Standard VHS cassettes (full-size)
- ✅ DVD discs
- ❌ VHS-C (compact VHS - not supported)
- ❌ Betamax (not supported)
- ❌ 8mm/Hi8 (not supported)

**Common Issues**:
- No video on screen: Check HDMI connection, verify tape is inserted
- Poor video quality: Tape may be damaged or degraded
- Tape won't eject: Power off, wait 10 seconds, power on and try again

## Audio Digitisation Equipment

### Tascam CD-A580

**Purpose**: Combined CD player and cassette recorder with USB recording

**Model**: CD-A580

**Key Features**:
- Records audio from CD or cassette to USB as MP3
- Independent operation (does not need ATEM Mini)
- Built-in cassette player
- CD player
- Simple controls on front panel

**Technical Specifications**:
- Recording Format: MP3 (various bitrates)
- Input Sources: CD, Cassette Tape
- Output: USB drive (front panel port)
- Recording Quality: Adjustable MP3 bitrate
- Display: LCD showing status and track info

**Physical Controls**:
- **USB port**: Front panel for USB drive
- **INPUT button**: Select CD or TAPE source
- **RECORD button**: Start/stop recording
- **PLAY button**: Start playback/recording
- **STOP button**: Stop playback/recording
- **Cassette door**: Top loading
- **CD tray**: Front loading
- **Display**: Shows recording status, track number, time

**Important Notes**:
- Recording is real-time (60 min tape = 60 min recording)
- Must select correct INPUT (CD or TAPE) before recording
- USB drive must be inserted before starting
- Wait for "REC" to appear on display before pressing PLAY

**Supported Formats**:
- ✅ Standard audio cassette tapes
- ✅ Standard audio CDs
- ✅ CD-R, CD-RW
- ❌ MiniDisc (not supported)
- ❌ DAT (not supported)

**Common Issues**:
- No recording started: USB not inserted or INPUT not selected
- Poor audio quality: Tape heads may need cleaning
- CD won't play: Disc may be scratched or dirty

## Monitor

**Purpose**: Display video preview from ATEM Mini

**Key Features**:
- Shows live video feed from VHS player
- Displays ATEM control interface
- HDMI input from ATEM Mini

**Physical Controls**:
- **CHROME button**: Located on underside of monitor (right-hand side)
  - Press to wake screen if off
  - Also accessible via remote if available

**Important Notes**:
- Screen should automatically display when equipment is powered on
- If screen is blank, check CHROME button first
- Verify HDMI cable connection from ATEM Mini to monitor

---

## USB Drives

**Requirements**:
- USB 2.0 or 3.0 compatible
- Formatted as FAT32 or exFAT
- Minimum 4GB capacity (8GB+ recommended)
- Sufficient free space for recording

**Recommendations**:
- Library-provided USB drives available (if offered)
- Patrons can bring their own
- Test USB drive before long recording sessions
- Format drive before use if it has issues

**Common Issues**:
- Drive not recognized: Try reformatting as FAT32
- Recording failed: Drive may be too slow or full
- File not appearing: Wait 30 seconds after stopping recording for file to finalize

## Physical Setup

### Cable Connections

1. **LG Player → ATEM Mini**:
   - HDMI cable from LG player OUT to ATEM Mini HDMI Input 1

2. **ATEM Mini → Monitor**:
   - HDMI cable from ATEM Mini HDMI OUT to Monitor IN

3. **Power**:
   - All devices plugged into power strip
   - Power strip easily accessible for patron reset if needed

### Labels and Markings

- **USB port on ATEM keypad**: Bright colored tape marking the location
- **CHROME button**: May need small label for visibility
- Equipment labels with model numbers for staff reference

### Station Layout

Recommended layout for patron ease of use:
1. Monitor front and center
2. LG player to the left (easy VHS insertion)
3. ATEM keypad center-right (easy reach to REC button)
4. Tascam to the right (separate audio station)
5. Clear workspace for patron materials

## Troubleshooting Quick Reference

### Video Recording Issues

| Problem | Solution |
|---------|----------|
| DISK light not turning green | Check USB drive is fully inserted in back port; try different USB drive |
| No video on screen | Press CHROME button on monitor underside; check HDMI cables |
| Recording has no sound | Verify Channel 1 ON button was pressed and sound bar was moving |
| VHS won't play | Check tape is inserted correctly; try rewind and play again |
| MP4 file not created | Ensure REC was pressed before PLAY; verify USB had enough space |

### Audio Recording Issues

| Problem | Solution |
|---------|----------|
| Tascam not recognizing USB | Insert USB into front port; wait for display confirmation |
| No recording started | Check INPUT is set to correct source (CD or TAPE) |
| Poor audio quality | Clean cassette heads; check tape condition |
| CD won't play | Clean disc; verify it's a supported format |

## Equipment Replacement

If equipment needs replacement:

1. **Document current setup**:
   - Take photos before disconnecting
   - Note cable routing
   - Record exact model numbers

2. **Replacement criteria**:
   - Same or equivalent model preferred
   - Must support same input/output formats
   - Verify compatibility with other equipment

3. **After replacement**:
   - Update all guides with new button names/locations
   - Take new photos for dashboard
   - Complete full verification checklist
   - Test with first-time user
